# SKYHAND — 모션인식 드론 시뮬레이터

웹캠으로 손을 인식해 드론을 조종하는 훈련 시뮬레이터입니다. 단일 정적 웹사이트(`index.html`)로 동작합니다.

## 로컬에서 실행하기 (내 컴퓨터)

### 방법 1 — 그냥 열기 (가장 간단)
`index.html` 파일을 더블클릭해서 크롬으로 엽니다. 카메라 권한을 **허용**하세요.

### 방법 2 — 로컬 서버로 열기 (권장, 배포 환경과 동일)
`start-server.bat` 파일을 더블클릭하면 로컬 서버가 뜨고 브라우저가 열립니다.
- 주소: `http://localhost:8000`
- `localhost`는 보안 연결로 취급돼 웹캠이 더 안정적으로 켜집니다.
- 끄려면 열린 검은 창(터미널)을 닫으세요.
- 파이썬이 없으면 아래 중 하나를 터미널에서 실행하세요.
  - `npx serve` (Node.js 설치 시)
  - 또는 크롬 확장/에디터의 Live Server

## 조작법 (한 손)
- 손바닥을 스틱처럼: 앞뒤/좌우 기울기 = 전진·뱅크, 손 높이 = 상승/하강, 손목 비틀기 = 회전
- `G` 속도 단수(1/2/3, 3단 250km/h) · `C` 중립 보정 · `V` 카메라 전환 · `T` 튜닝 · `Esc` 메뉴
- 키보드: `W/S` 상승·하강, `A/D` 회전, 방향키 이동, `Space` 액션

## 나중에 배포 (아직 연동 안 함)
- **GitHub**: 이 폴더를 그대로 레포에 올리면 됩니다.
- **Vercel**: 레포를 import 하면 정적 사이트로 자동 배포됩니다(빌드 설정 불필요, 루트의 `index.html` 서빙).
